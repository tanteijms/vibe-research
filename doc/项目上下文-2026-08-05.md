# 项目上下文（2026-08-05）

这是给后续继续推进 `vibe-research / Harness x Hermes` 的交接页。

一句话版本：我们不是在做 another agent framework，而是在做 long-horizon software-engineering agents 的 runtime support。

## 当前主线

三条稳定叙事已经定住：

1. Hydratable Scene / Context Lifecycle Contract

   恢复的不是 transcript，而是可验证的执行现场。

2. Evidence-Governed Memory Commit

   记忆不是随写随用，而是要经过 validation / commit / provenance / retraction。

3. Evidence-Retaining Replay Diagnosis

   回放不是看日志，而是保留证据链来定位 failure / drift / repair hint。

## 当前设计分层

- Harness：policy、approval、tool/effect gating、checkpoint / resume、权限边界。
- Hermes：hydration / dehydration、memory commit、evidence ledger、trace envelope。
- Benchmark：issue-to-patch、artifact replication、incident RCA 三类任务，以及 synthetic matrix、local toy run、official ingest contract。
