## 2. 今天新补的研究信号

今天这一轮重点不是再泛泛找 agent paper，而是专门围绕长程上下文、中断恢复、证据链和 runtime governance 找能进入设计的信号。

### 2.1 Context control plane

相关来源：

- Learning Agent-Compatible Context Management for Long-Horizon Tasks (AdaCoM)
- LLM Agents Are Latent Context Managers
- ECHO selective turn memory

设计吸收：

- context 不是 prompt summary 的副产物，而应该是 runtime control plane。
- context action 应显式化：retain / drop / compress / pin / branch / rehydrate。
- agent 需要可观测的 context dashboard：当前 pinned facts、artifact refs、memory segments、retention budget、drift warnings。
- turn-level memory 要保留 source-level provenance，否则后续 replay 和 credit assignment 会断。

### 2.2 Memory as action

相关来源：

- Memory as Action: Autonomous Context Curation for Long-Horizon Agentic Tasks
- Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents

设计吸收：

- memory mutation 不能是后台隐式副作用。
- store / retrieve / update / summarize / discard 都应该是 policy-governed action。
- memory commit 不只保留 evidence receipt，还应保留 action-level provenance 和 trajectory fracture point。

### 2.3 Artifact / execution provenance

相关来源：

- Durable intermediate artifacts
- Evidence tracing and execution provenance
- AgentTrails
- Traccia

设计吸收：

- artifact 是 first-class maintained state，不是普通文件列表。
- hydration manifest 后续要恢复 artifact lineage、supersession history、current-state resolution 和 dependency graph。
- TraceEnvelope 后续应编译为 provenance graph，再投影到 replay / diagnosis / evidence support。
- telemetry、guardrail assessment、execution lineage 可以进一步收束成 hashed trace ledger。

### 2.4 Proof-derived authorization

相关来源：

- Verifiable Agentic Infrastructure: Proof-Derived Authorization for Sovereign AI Systems

设计吸收：

- authorization 不应该只看 standing identity 或 approve token。
- effect commit 前应重新检查 proof object、evidence chain、execution identity 和 authority freshness。
- 这会把现有 `PermissionGraph` / approval receipt 推向 `ProofDerivedAuthorization`。

## 4. 当前最该补的工程对象

下一步建议优先级：

1. `ContextControlPlane`
   - 显式记录 context actions。
   - 输出 context dashboard。
   - 和 hydration manifest / compaction verifier 接起来。

2. `ArtifactLineageVerifier`
   - 支持 artifact supersession。
   - 支持 dependency-aware current state。
   - 给 FSE artifact package 更强 provenance。

3. `ProvenanceGraphCompiler`
   - 从 TraceEnvelope 编译 execution provenance graph。
   - 输出 evidence support graph。
   - 服务 replay diagnosis 和 human debugging。

4. `ProofDerivedAuthorization`
   - 从 approval token 升级到 proof object + evidence chain。
   - 用于 effectful action commit boundary。

5. `UnifiedMemoryActionPolicy`
   - 把 memory ops 作为显式 action 管。
   - 和现有 `MemoryCommitProtocol` 合并。
